# All About Data & More

Practical projects and tutorials for people becoming job-ready in data analysis, data science and data engineering. Part of the [All About Data & More](https://aaboutdata.substack.com) publication by [Samuel Shaibu](https://shaibusamuel.com).

Every project here is built the way real work should be: real data where possible, tests, CI/CD, and documentation that explains *why*, not just *what*. The mistakes are documented too, because that's where most of the learning is.

## Projects

| Project | What it covers |
|---|---|
| [energy-analytics-platform](https://github.com/all-about-data-and-more/energy-analytics-platform) | An AWS pipeline on real electricity grid outage data, and an honest model evaluation: why 82% accuracy was really 67%. |
| [retail-customer-intelligence](https://github.com/all-about-data-and-more/retail-customer-intelligence) | Customer segments, churn risk and lifetime value from raw e-commerce data, in dbt on Databricks. |
| [ai-trip-and-outdoor-activity-planner](https://github.com/all-about-data-and-more/ai-trip-and-outdoor-activity-planner) | A tool-calling AI agent on Databricks that plans trips from live forecasts and its own search over destination data. |
| [weather-mcp-server](https://github.com/all-about-data-and-more/weather-mcp-server) | Weather and air-quality tools exposed to AI agents through an MCP server. |
| [shared-databricks-utils](https://github.com/all-about-data-and-more/shared-databricks-utils) | Logging, configuration, schema validation and retries that every Databricks pipeline ends up needing. |
| [databricks-bundle-template](https://github.com/all-about-data-and-more/databricks-bundle-template) | A starting point for Databricks projects, with Asset Bundles, Terraform and CI/CD set up. |
| [lakebase-support-app](https://github.com/all-about-data-and-more/lakebase-support-app) | A support ticketing app on Databricks Lakebase (managed Postgres). |

Bootcamp builds: [lakebase app day 1](https://github.com/all-about-data-and-more/databricks-lakebase-app-day-1), [day 2](https://github.com/all-about-data-and-more/databricks-lakebase-app-day-2) and the [weather app](https://github.com/all-about-data-and-more/databricks-lakebase-weather-app).
